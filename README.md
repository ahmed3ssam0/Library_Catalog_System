# Library Management System

A Java-based application designed to manage library operations efficiently through a simple graphical interface.

## Features

* Add and manage books
* Search for books
* Borrow and return books
* User-friendly interface
* Organized data management

## Technologies Used

* Java
* JavaFX
* Object-Oriented Programming (OOP)

## Learning Outcomes

This project enhanced my skills in Java development, GUI design, and implementing real-world management systems.
